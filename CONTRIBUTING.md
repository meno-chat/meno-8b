# Contributing to Meno

Thanks for your interest. The project is early, so the most useful contributions right now are:

- **Tutoring examples and rubrics** that are original work (not copied from TutorBench or any other benchmark).
- **Bug reports and fixes** for scripts in this repo.
- **Feedback** on the approach, opened as an issue.

## Ground rules
- Do not submit TutorBench test samples or any data derived from them as training data. This protects the integrity of any benchmark result we report.
- Only contribute data you have the right to share, under a license compatible with Apache 2.0.
- Never commit API keys, tokens, or personal data.

## How to contribute
1. Open an issue describing what you want to change.
2. Fork the repo, make your change on a branch, and open a pull request.
3. Keep changes small and focused.
